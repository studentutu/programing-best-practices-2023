| Topic | Key Insight |
|-------|-------------|
| Project Type | Documentation/knowledge repo, not an application |
| Primary Deliverable | README.md (~1000+ lines, 30+ languages) |
| Tooling | Python crawler + Bash scripts for offline access |

## Architecture Patterns
- Static markdown knowledge base with optional tooling layer
- Multi-editor AI support via config files (5+ editors)
- Template system for integrating into other projects

## Gotchas & Pitfalls
- README.md is very large; use section navigation
- Crawler requires Python venv setup before use
- Content/ and summaries/ directories are generated, not committed
